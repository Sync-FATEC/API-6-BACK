Antes de rodar os arquivos é necessário rodar: pip install git+https://github.com/urbanogilson/SICAR

Para windows baixe o tesseract no link: https://github.com/UB-Mannheim/tesseract/wiki

Primeiro execute o coletor_sicar.py para baixar os dados 
Segundo execute processar_sicar.py para converter o ZIP em geojson

O coletar_sicar.py é a versão unificada do coletor_sicar.py e o processar_sicar.py

Depois de rodar os dois só seguir com o processo dos demais scripts
